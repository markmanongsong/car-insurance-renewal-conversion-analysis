
# 📊 Car Insurance Renewal Conversion Analysis

## 🎯 Project Overview

This project investigates the significant decline in the insurance renewal conversion rate from **80% in 2025** to **50% in 2026**. The primary objective is to identify the factors contributing to the decrease and determine whether the organizational change that merged **Renewals** and **New Business** responsibilities into a single agent role affected renewal performance.


---

## 🚨Problem Statement

The renewal conversion rate dropped from 80% in 2025 to 50% in 2026 after agents began handling both Renewals and New Business instead of specializing in a single line of business. This project aims to identify the factors driving the decline and provide data-driven recommendations to restore or exceed the previous 80% renewal conversion rate.
